# 🚀 Quick Start Guide

## For Clients / Non-Technical Users

### ✅ Start the Application

**Just double-click:** `START-HERE.bat`

That's it! The script will:
1. Stop any old services
2. Start all 5 services (in separate windows)
3. Wait 20 seconds
4. Automatically open your browser to the app

---

## 🎯 How to Use

### 1. Login
- Username: `koshai` (or create your own)
- Password: (your password)

### 2. Create a Meeting
- Click "Create Meeting"
- Name it anything (e.g., "Demo Meeting")

### 3. Join the Meeting
- Click "Join"
- Allow camera/microphone when asked

### 4. Enable Voice Translation
- Click the **📝** button (starts transcription)
- Click the **👂** button (opens audio settings)
- Select **🔊 Translated**
- Now speak in any language - you'll hear English!

### 5. Test It!
Say in Spanish: **"Hola, ¿cómo estás?"**
You'll hear: **"Hello, how are you?"** (in English voice)

---

## 🛑 Stop the Application

**Double-click:** `stop-all.bat`

This closes all services.

## 🆘 Problems?

### Services won't start
1. Run `stop-all.bat`
2. Wait 5 seconds
3. Run `START-HERE.bat` again

### Can't hear translated voice
1. Check that 🔊 button is **blue**
2. Check volume slider is up
3. Make sure you clicked 📝 first

### No transcription appearing
1. Click the 📝 button
2. Make sure microphone is enabled
3. Speak clearly and wait 2-3 seconds
